# Code of Conduct

This project expects professional, respectful collaboration.

## Expected Behavior

- Keep feedback specific, technical, and actionable.
- Respect privacy concerns around local desktop context.
- Avoid harassment, personal attacks, discriminatory language, and repeated
  off-topic arguments.
- Keep issues and pull requests scoped to Flowline's local-first macOS goals.

## Unacceptable Behavior

- Harassment or abusive comments
- Doxxing or sharing private information
- Spam, brigading, or coordinated disruption
- Publishing sensitive security details before maintainers can respond

## Enforcement

Maintainers may edit, hide, or delete comments; lock threads; close issues; or
block users who violate these expectations.

Security reports should follow `SECURITY.md`, not public issue threads.
